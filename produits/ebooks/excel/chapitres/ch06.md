## Une macro, c'est quoi ?

Une macro est une petite liste d'ordres qu'Excel exécute à ta place, toujours dans le même ordre. Tu la lances d'un clic au lieu de refaire dix manipulations à la main.

Elle est écrite dans un langage appelé VBA. Tu n'as pas besoin de l'apprendre : l'IA l'écrit, et tu vérifies. Les outils VBA se trouvent dans l'onglet Développeur, « masqué par défaut » (aide Microsoft, « Démarrage rapide : créer une macro »).

## Le besoin : trier et mettre en gras

Tu tiens la liste des ventes du jour. Chaque soir, tu veux la ranger du plus gros montant au plus petit, puis mettre en gras les ventes de plus de 50 000 F. Notre tableau compte 7 ventes en désordre, dont une à exactement 50 000 F : ce sera notre test.

1: 72,54 g4 | La plus grosse vente, 120 000 F, est au milieu de la liste.

## Demander la macro à ChatGPT

:::prompt Prompt 6.1
J'utilise Excel 2016 en français. Écris une macro VBA. Feuille « Ventes », en-têtes en ligne 1, données dès la ligne 2 : A client, B produit, C montant en FCFA. La macro trie la liste du plus gros au plus petit montant, puis met en gras les montants supérieurs à 50 000. Donne le code complet, puis 3 lignes de mode d'emploi.
:::

Envoyé le 10 octobre 2026 à gpt-4o-mini et gpt-5-mini. Voici la réponse de gpt-4o-mini, la plus courte (sans ses commentaires) :

:::resultat Réponse réelle de ChatGPT (gpt-4o-mini) | mono
Sub TrierEtMettreEnGras()
    Dim ws As Worksheet
    Set ws = ThisWorkbook.Sheets("Ventes")
    ws.Range("A1:C" & ws.Cells(ws.Rows.Count, "A").End(xlUp).Row).Sort _
        Key1:=ws.Range("C2"), Order1:=xlDescending, Header:=xlYes
    Dim cell As Range
    For Each cell In ws.Range("C2:C" & ws.Cells(ws.Rows.Count, "C").End(xlUp).Row)
        If cell.Value > 50000 Then
            cell.Font.Bold = True
        End If
    Next cell
End Sub
:::

## Nous l'avons testée pour de vrai

Nous n'avons pas Excel 2016 dans notre laboratoire. LibreOffice Calc sait lire une partie du VBA en « mode compatibilité ». Un script ouvre un classeur neuf, colle le code de l'IA, le lance, puis contrôle l'ordre des montants, les clients restés avec leur vente et le gras.

## Le piège : le gras qui reste

Nous avons ensuite baissé la vente d'Aminatou de 120 000 à 5 000 F et relancé la macro de gpt-4o-mini. Le tri est bon, mais 5 000 F reste en gras.

:::capture ../../preuves/sortie/c6-macro-t02-gpt4omini/rejeu.png | Capture réelle, deuxième lancement de la macro de gpt-4o-mini.
1: 72,93 g4 | 5 000 F est toujours en gras : la macro ne retire jamais le gras.
:::

:::erreur
La macro de gpt-4o-mini ajoute le gras, mais ne l'enlève jamais. Dès qu'un chiffre baisse, une vente est en gras à tort, sans message d'erreur. Celle de gpt-5-mini, plus longue, contient `Else cell.Font.Bold = False` : même test, 5 000 F n'est plus en gras.
:::

## Ce que ce test prouve, et ce qu'il ne prouve pas

Nous avons testé dans LibreOffice, pas dans Excel : la logique est bonne, mais rien ne prouve que la macro tourne dans Excel 2016. Nous avons donc relu chaque objet dans la documentation Microsoft Learn (en français). `Range.Sort` trie, et `Header` vaut « xlNo » par défaut : `xlYes` est donc juste. `Range.End(xlUp)` revient à appuyer sur Fin + Flèche vers le haut. `Font.Bold` vaut True pour du gras.

:::astuce
Notre test ajoute une ligne « Option VBASupport 1 » en tête. Sans elle, LibreOffice n'a pas exécuté la macro. Dans Excel, tu ne la colles jamais : « ne marche pas dans LibreOffice » ne veut pas dire « faux dans Excel ».
:::

## Coller la macro dans Excel 2016

Chaque étape vient d'une page Microsoft en français. Nous ne les avons pas rejouées dans un vrai Excel 2016 : si un menu a un autre nom chez toi, cherche le plus proche.

1. Onglet Développeur : « Sous l'onglet Fichier, accédez à Options > Personnaliser le ruban », puis coche Développeur (aide « Afficher l'onglet Développeur »).
2. Alt + F11 « ouvre le Microsoft Visual Basic For Applications Editor » (aide « Raccourcis clavier dans Excel »).
3. Dans l'éditeur : « Insérer > un module » (aide « Créer des fonctions personnalisées »). ChatGPT dit « Insertion > Module » : même menu.
4. Colle le code dans la fenêtre blanche, puis ferme l'éditeur.
5. Onglet Développeur, Macros, choisis la macro, Exécuter (aide « Exécuter une macro dans Excel »).
6. Enregistre en « Classeur Excel Macro-Enabled (*.xlsm) », puis rouvre le fichier pour vérifier que les macros s'exécutent (aide Microsoft sur l'enregistrement en .xlsm).

:::erreur
ChatGPT conclut : « annulez (Ctrl+Z) après exécution si nécessaire ». Microsoft écrit que certaines instructions VBA effacent la liste d'annulation : « la pile d'annulation sera effacée ». Ne compte pas sur Ctrl+Z, garde une copie du fichier avant de lancer.
:::

## La même chose dans Google Sheets

Google Sheets n'utilise pas VBA mais Apps Script, un langage proche du JavaScript. Google écrit : « Pour créer un script lié, sélectionnez Extensions > Apps Script dans Sheets ».

:::prompt Prompt 6.2
J'utilise Google Sheets en français. Écris un script Google Apps Script. Feuille « Ventes », en-têtes en ligne 1, données dès la ligne 2 : A client, B produit, C montant en FCFA. Le script trie la liste du plus gros au plus petit montant, puis met en gras les montants supérieurs à 50 000. Donne le code complet, puis 3 lignes de mode d'emploi.
:::

:::resultat Extrait de la réponse réelle de ChatGPT (gpt-5-mini) | mono
var dataRange = sheet.getRange(2, 1, lastRow - 1, 3);
dataRange.sort({ column: 3, ascending: false });
...
if (!isNaN(montant) && montant > 50000) {
  montantCell.setFontWeight('bold');
} else {
  montantCell.setFontWeight('normal');
}
:::

Le script complet fait une trentaine de lignes ; nous n'en montrons que le coeur. Nous n'avons pas pu l'exécuter, faute de compte de test. Nous avons seulement vérifié, dans la documentation de Google (developers.google.com/apps-script), que `getRange(ligne, colonne, nbLignes, nbColonnes)`, `sort({ column: 3, ascending: false })` (l'écriture de l'exemple de Google) et `setFontWeight('bold')` ou `'normal'` existent.

À la première exécution, Google écrit : « une boîte de dialogue d'autorisation s'affiche lors de son exécution ». L'IA propose aussi un déclencheur automatique : nous ne l'avons pas vérifié, lance d'abord le script à la main.

## Comprendre avant de lancer

Ne lance jamais une macro que tu ne comprends pas : elle peut supprimer des fichiers. Demande à l'IA de l'expliquer ligne par ligne.

:::prompt Prompt 6.3
Explique cette macro Excel ligne par ligne, pour un débutant, en français simple. Dis aussi si elle peut supprimer ou envoyer quelque chose. [colle la macro]
:::

:::resultat Extraits de la réponse réelle de ChatGPT (gpt-5-mini) | mono
3) Set ws = ThisWorkbook.Sheets("Ventes")
- Assigne la feuille nommée "Ventes" de ce classeur à la variable "ws".
- Si la feuille "Ventes" n'existe pas, la macro générera une erreur.

Supprimer : Non, cette macro ne supprime pas de lignes, de cellules ni de fichiers.
Envoyer : Non, elle n'envoie rien (pas d'e-mails, pas d'accès réseau).
:::

La réponse complète explique les 9 lignes une par une. Sur une macro piégée (elle supprime des fichiers .xlsx puis ouvre une page web), l'IA a répondu « Ne la lancez pas ».

:::erreur
Dans cette seconde réponse, l'IA a écrit l'adresse « https://exemple.test » et perdu la fin, « /bonus ». Une explication d'IA peut se tromper sur un détail : relis le code toi-même.
:::

## Les macros des fichiers reçus

Microsoft écrit que les macros sont « souvent utilisées par des personnes mal intentionnées pour distribuer des programmes malveillants » (aide « Une macro potentiellement dangereuse a été bloquée »). Quand tu ouvres un fichier avec macros, Excel affiche un avertissement de sécurité. L'aide Microsoft dit :

- « N'activez jamais les macros dans un fichier Microsoft 365 si vous n'êtes pas sûr de savoir ce que font ces macros ».
- « Vous n'avez pas besoin d'activer les macros pour afficher ou modifier le fichier. »
- Le réglage prudent : « Désactiver toutes les macros avec notification », dans Fichier > Options > Centre de gestion de la confidentialité.

:::recap
- Une macro est une liste d'ordres lancée d'un clic : l'IA l'écrit.
- Teste sur une copie, avec un cas limite (50 000 pile) et un second lancement.
- Excel : Alt + F11, ajouter un module, coller, exécuter, enregistrer en .xlsm.
- Google Sheets : Extensions > Apps Script, avec un autre code.
- Fais expliquer chaque macro. N'active jamais celle d'un inconnu.
:::
